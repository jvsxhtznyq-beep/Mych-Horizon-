# Glowmoss Caverns

A pixel-art cave platformer: guide a lantern-bearing explorer through three glowing caverns, collect glowmoss, stomp slimes, bats and spore turrets, and find the way out.

## Play

Open `index.html` (the single-file build) in a modern browser. No installation or server needed.

| Action | Keyboard | Gamepad | Touch |
|---|---|---|---|
| Run | Arrow keys or A/D | Left stick or d-pad | On-screen arrows |
| Jump (hold for higher) | Space, Z, Up or W | A | JUMP |
| Pause | Esc or P | Start | II button |

Progress, best scores and settings are saved in the browser (local storage). Settings include volume levels, screen shake, reduced flashing, a frame-rate display and touch controls.
