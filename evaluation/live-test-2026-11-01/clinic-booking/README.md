# clinic-booking

Appointment booking for a small physiotherapy clinic: patients book 30-minute slots between 09:00 and 17:00, staff sign in to manage the schedule.

- `booking/` application code (models, storage, scheduler, auth, reports, formatting)
- `tests/` unit tests: `python3 -m unittest discover -s tests`
- `scripts/` operational scripts for the production server
- `docs/decisions/` decision records
